Comercio electrónico

El Catrín: tienda en línea

Problema

El negocio necesitaba vender en línea y mantener su inventario organizado, sin atender cada pedido de forma manual.

Solución

Desarrollé una tienda web corporativa con una base de datos relacional para el inventario y un sistema de pedidos automatizados.

Tecnologías

Desarrollo web · Base de datos relacional · Automatización de pedidos

Inicio de la tienda y catálogo por categorías con el carrito de pedido, que se envía por WhatsApp.

Inteligencia artificial

Astra: asistente con IA para entrevistas técnicas y estudio

Problema

Practicar entrevistas técnicas es difícil sin alguien que haga las preguntas y dé retroalimentación, y resolver dudas de una materia fuera de clase no siempre es posible.

Solución

Desarrollé Astra con IA generativa en dos aplicaciones web desplegadas en la nube: un simulador que entrevista según el puesto elegido (por ejemplo, Desarrollador Python Junior), con tres preguntas e indicador de progreso, y un asistente académico.

Tecnologías

Python · Streamlit · Gemini API (SDK de Google GenAI) · Despliegue en la nube

Simulador de entrevistas técnicas y asistente virtual de Sistemas Inteligentes, ambos desplegados en Streamlit.

Desarrollo frontend

LectorWeb: aplicación web de lectura interactiva

Problema

Leer obras largas en la web resulta incómodo cuando no hay una forma ágil de encontrar un libro, ubicar un capítulo o ajustar la lectura.

Solución

Desarrollé el frontend de una aplicación de lectura interactiva: una biblioteca con buscador, una lista de capítulos con búsqueda y orden, y un lector con selector de capítulo, navegación anterior y siguiente, modo oscuro y pantalla completa.

Tecnologías

TypeScript

Biblioteca, lista de capítulos y lector con selector de capítulo, modo oscuro y pantalla completa.
